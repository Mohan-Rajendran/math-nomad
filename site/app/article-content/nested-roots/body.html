Introduction

A sequence you might already know

\[ \sqrt{2+\sqrt{2+\sqrt{2+\cdots}}}=2. \]

For x > 0, let

\[ \sqrt[x]{\,x+\sqrt[x]{\,x+\sqrt[x]{\,x+\cdots}}}=L. \]

Two questions

  1. For which values of x does L make sense?
  2. What type of values can L take?

Panel 1

Experimentation

For a particular value of x, compute

\[ \sqrt[x]{x},\quad \sqrt[x]{\,x+\sqrt[x]{x}},\quad \sqrt[x]{\,x+\sqrt[x]{\,x+\sqrt[x]{x}}},\ \ldots \]

Count how many steps it needs before the terms settle. We see a gap (α, 1] for which

\[ L=\sqrt[x]{\,x+\sqrt[x]{\,x+\sqrt[x]{\,x+\cdots}}}\;\longrightarrow\;\infty. \]

The answer to question 1

L makes sense exactly when

\[ 0 < x \le \alpha \qquad\text{or}\qquad x > 1 \]

where α is a particular number between 0 and 1: α = 0.3601300017…

Panel 2

Where does the gap come from?

If L is that infinite root, then it must satisfy

\[ L^{x}-L=x \]

Read it as a picture. The curve \(L^{x}-L\) rises to a peak and then falls away. A resting place exists only where that curve reaches the height x.

Sandbox 2 · The hill and the line

The bar is the same gap in both charts: left, between the peak and the line; right, between the two curves.

Those two effects race each other. The peak wins for small x, the line wins for large x, and they are level at exactly one value. That value is α.

The boundary constant

α is the one number in (0, 1) with

\[ \alpha^{\frac{\alpha}{1-\alpha}}=\frac{\alpha}{1-\alpha} \]

Panel 3

Which solution is L?

For \(0 < x < \alpha\) the equation \(L^{x}-L=x\) has two positive solutions. Only the smaller one is L.

The sequence starts at \(\sqrt[x]{x}\) and every step makes it larger. It therefore climbs until it meets a solution, and it meets the smaller one first, so it stops there. The larger solution is a ceiling the sequence never reaches: a sequence would have to begin above it to escape, and \(\sqrt[x]{x}\) never does.

Reading the graph

The solid curve is L itself. The dotted curve is the second solution, which is never attained, so it is ignored. As x grows the two move together, collide at α and vanish: with no solution left, L = ∞. That is the gap. Past x = 1 a single solution returns and L makes sense again.

Panel 4

What kind of number is α?

A number is algebraic if it solves some polynomial equation with whole-number coefficients. Every fraction \(p/q\) does, since it solves \(qT-p=0\); so does \(\sqrt2\), which solves \(T^{2}-2=0\); so does the golden ratio, which solves \(T^{2}-T-1=0\). A number that solves no such equation is transcendental. Almost every number is therefore transcendental. Proving it of any particular number is another matter: π and e took until the 1870s and 1880s.

One theorem tells the layers apart.

Gelfond–Schneider, 1934 · Hilbert's 7th problem

If a and b are algebraic, \(a\neq 0,1\), and b is irrational, then \(a^{b}\) is transcendental.

The boundary constant is transcendental

Panel 2 defined α by exactly this: a power of α equal to a simple fraction in α. If α were algebraic, the theorem would make one side transcendental and the other algebraic — impossible. So α is transcendental, and so is the value 0.2027… that the sequence settles on there.

And what about L?

The same theorem, applied to \(L^{x}-L=x\), sorts every value of x into one of three cases.
