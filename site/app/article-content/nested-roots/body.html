Introduction

A sequence you might already know

\[ \sqrt{2+\sqrt{2+\sqrt{2+\cdots}}}=2. \]

For x > 0, consider

\[ \sqrt[x]{\,x+\sqrt[x]{\,x+\sqrt[x]{\,x+\cdots}}}=L. \]

We interpret this expression as the limit of its finite truncations. More precisely, define

\[ a_0=0,\qquad a_{n+1}=(x+a_n)^{1/x}\quad(n\ge0). \]

We write \(L=L(x)=\lim_{n\to\infty}a_n\) only when this limit is finite.

Two questions

  1. For which values of x does the sequence have a finite limit?
  2. When the limit exists, is it algebraic or transcendental?

Panel 1

Experimentation

For a particular value of x, compute

\[ \sqrt[x]{x},\quad \sqrt[x]{\,x+\sqrt[x]{x}},\quad \sqrt[x]{\,x+\sqrt[x]{\,x+\sqrt[x]{x}}},\ \ldots \]

The experiment suggests a gap, \(\alpha<x\le1\), in which the terms grow without bound:

\[ a_n\longrightarrow+\infty\qquad(n\to\infty). \]

For convergent parameters, the experiment records the first index \(n\ge1\) for which \(\lvert a_{n+1}-a_n\rvert<10^{-d}\). A small change between successive terms does not guarantee that either term is within \(10^{-d}\) of the limit. The convergence verdict uses the mathematical criterion proved below, not this numerical stopping rule.

The answer to question 1

The sequence has a finite limit exactly when

\[ 0 < x \le \alpha \qquad\text{or}\qquad x > 1 \]

where α is a particular number between 0 and 1: \(\alpha\approx0.36013000173217046\).

Panel 2

Where does the gap come from?

If the sequence has a finite limit L, continuity gives

\[ L^{x}-L=x \]

For \(0<x<1\), read this as a picture: the curve \(y=t^x-t\), for \(t\ge0\), rises to a peak and then falls. A positive fixed point exists exactly where this curve meets the horizontal line \(y=x\).

The sequence is increasing. Every positive fixed point bounds it above, because the map \(t\mapsto(x+t)^{1/x}\) is increasing. Thus the sequence converges to a finite limit if and only if a positive fixed point exists; otherwise its terms tend to infinity.

Sandbox 2 · The hill and the line

The bar is the same gap in both charts: left, between the peak and the line; right, between the two curves.

For \(0<x<1\), the peak occurs at \(t=x^{1/(1-x)}\) and has height

\[ M(x)=(1-x)x^{x/(1-x)}. \]

This height decreases from 1 to 0 as x increases from 0 to 1: \((\log M(x))'=\log x/(1-x)^2<0\). Meanwhile, the required height x increases. The two are equal at exactly one value, α.

The boundary constant

α is the one number in (0, 1) with

\[ \alpha^{\frac{\alpha}{1-\alpha}}=\frac{\alpha}{1-\alpha} \]

At \(x=1\), the recurrence is \(a_{n+1}=1+a_n\), so \(a_n=n\) and the sequence diverges. For \(x>1\), the function \(t^x-t\) is nonpositive on \([0,1]\) and strictly increases from 0 to infinity for \(t>1\). It therefore meets \(y=x\) exactly once, giving a finite limit.

Panel 3

Which solution is L?

For \(0 < x < \alpha\), the equation \(t^{x}-t=x\) has two positive solutions. Only the smaller one is L.

The first positive term is \(a_1=\sqrt[x]{x}\). The sequence increases and stays strictly below the smaller solution. It therefore converges to that solution without reaching it in finitely many steps. The larger fixed point acts as a ceiling: any nonnegative starting value below it converges to the smaller fixed point, a start exactly at it stays fixed, and a start above it diverges to infinity.

Reading the graph

The solid curve gives the limit of the original sequence. The dotted curve is the larger fixed point, which is not the limit of that sequence. The two fixed points merge at α, where the sequence still converges. For \(\alpha<x<1\), there is no positive fixed point, and the sequence diverges; it also diverges at \(x=1\). For \(x>1\), there is a unique positive fixed point and a finite limit.

Panel 4

What kind of number is α?

A number is algebraic if it is a root of a nonzero polynomial with integer coefficients. Every rational number \(p/q\), with \(q\ne0\), is algebraic, since it solves \(qT-p=0\). The same is true of \(\sqrt2\), which solves \(T^{2}-2=0\), and the golden ratio, which solves \(T^{2}-T-1=0\). A number that solves no such equation is transcendental. The algebraic numbers form a countable set, so almost every real number is transcendental. Proving it for a particular number is another matter: the proofs for e and π date from 1873 and 1882, respectively.

A theorem about powers gives us a way to prove transcendence.

Gelfond–Schneider, 1934 · Hilbert's 7th problem [6]

If a and b are real algebraic numbers, \(a>0\), \(a\neq1\), and b is irrational, then \(a^{b}\) is transcendental.

The boundary constant is transcendental

First, α is irrational. Suppose \(\alpha=p/q\) in lowest terms, with \(0<p<q\). Raising its defining equation to the power \(q-p\) gives

\[ \left(\frac pq\right)^p= \left(\frac{p}{q-p}\right)^{q-p}. \]

Both fractions are in lowest terms, so their denominators must agree: \(q^p=(q-p)^{q-p}\). This is impossible because \(q\) and \(q-p\) are coprime and \(q>1\).

If α were algebraic, the exponent \(\alpha/(1-\alpha)\) would therefore be algebraic and irrational. Gelfond–Schneider would make \(\alpha^{\alpha/(1-\alpha)}\) transcendental, whereas the defining equation makes it equal to the algebraic number \(\alpha/(1-\alpha)\). This contradiction proves that α is transcendental.

At the boundary, the finite limit is

\[ L(\alpha)=\frac{\alpha^2}{1-\alpha} \approx0.20268744979246145. \]

This limit is also transcendental. If it were algebraic, the equation \(\alpha^2+L(\alpha)\alpha-L(\alpha)=0\) would make α algebraic, since a root of a nonzero polynomial with algebraic coefficients is algebraic.

And what about L?

Whenever the sequence has a finite limit, elementary algebra and Gelfond–Schneider give the following conclusions.

For rational \(x=p/q>0\) in lowest terms, raising \(L^{p/q}=L+p/q\) to the power \(q\) gives a nonzero polynomial equation with integer coefficients:

\[ q^qL^p-(qL+p)^q=0. \]

A finite limit satisfies \(L>0\) and \(L\ne1\), since substituting \(L=1\) into \(L^x=L+x\) would give \(x=0\). If x is algebraic and irrational, an algebraic limit would make \(L^x\) transcendental by Gelfond–Schneider, contradicting \(L^x=L+x\). The theorem gives no such general classification when x is transcendental. Particular cases can still be settled: at \(x=\alpha\), the limit is transcendental.
